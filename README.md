# Fast machine learning surrogates for microstrip line impedance and patch antenna resonant frequency

Comparison of six regression models (linear regression, polynomial regression, decision tree, random forest,
support vector regression, neural network) that predict the characteristic impedance **Z0** of a microstrip line and
the resonant frequency **fr** of a rectangular patch antenna from geometry. The method follows
Balaji and Raghavan, arXiv:2406.04357, and extends it with a six-model benchmark, an extrapolation test,
repeated splits, learning curves and ablations.

Team: Madhesh S (M26ECM506), Harsh Prabha Bhaina (M26ECM503), Gayatri Supraja (M26ECM505), IIT Jodhpur.

## Main results (random test set, 1,500 samples per problem)
| Model | Z0 mean error (%) | Z0 within 1% (%) | fr mean error (%) | fr within 1% (%) |
|---|---|---|---|---|
| Linear regression | 19.07 | 2.1 | 9.11 | 7.8 |
| Polynomial (degree 6) | 0.189 | 99.3 | 0.088 | 99.8 |
| Decision tree | 0.951 | 64.3 | 2.98 | 22.8 |
| Random forest | 0.364 | 94.9 | 1.29 | 53.8 |
| SVR (RBF) | 0.352 | 98.8 | 0.187 | 99.9 |
| Neural network | 0.529 | 87.1 | 0.760 | 71.4 |

On an unseen W/h range (train W/h < 7, test 8-10) the ranking changes: polynomial regression is worst for Z0,
the neural network is best. Full tables, figures and discussion: `report/report.pdf`.
The data are synthetic (analytical formulas); no comparison with HFSS/ADS has been made yet.

## Quick start
```
pip install -r requirements.txt        # or: conda env create -f environment.yml
python reproduce.py                    # runs every step (about ten minutes on one CPU core)
```
Single steps: `python src/generate_data.py`, `python src/train_models.py`, `python src/extrapolation_test.py`,
`python src/extra_experiments.py`, `python src/error_analysis.py`, `python src/save_checkpoints.py`, `python src/make_report_figure.py`.

## Predict one antenna with a saved checkpoint
```
python src/predict_single.py line  --wh 5 --er 4.4 --model "SVR (RBF)"
python src/predict_single.py patch --w 12 --l 9 --h 1.6 --er 4.4 --model "Polynomial regression"
```
Predictions are only reliable inside the training range (W/h 1-10, eps_r 2.2-12; patch L 5-15 mm, h 0.5-3 mm).

## Checkpoints and data
Checkpoints are in `checkpoints/` (all below 0.3 MB). The two random-forest checkpoints (about 32-34 MB) are not
kept in the repository; see `checkpoints/CHECKPOINTS.md` for the justification and recreate them with
`python src/save_checkpoints.py`. Datasets are small (< 1 MB) and included; no external data are used.

See `REPRODUCIBILITY.md` for the reproducibility statement and `docs/COMMIT_GUIDE.md` for the commit history.
